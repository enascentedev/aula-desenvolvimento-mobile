# Mapa da Turma — dinâmica do slide 04

Resolve um problema real dos 30 minutos de apresentação: **cada aluno fala 1
minuto e os outros 24 desligam.** Quem já falou relaxa, quem não falou ensaia a
própria fala. Ninguém escuta ninguém.

A dinâmica mantém a turma inteira ativa e, de quebra, produz um diagnóstico
visual que serve de gancho para o slide 05.

---

## Como funciona

**Antes de começar as apresentações**, desenhe no quadro:

```
   ┌──────────────────────────────────────────────────────────┐
   │            O QUE ESTA TURMA JÁ SABE                      │
   ├──────────────┬──────────────┬──────────────┬─────────────┤
   │  LINGUAGENS  │     WEB      │    DADOS     │ FERRAMENTAS │
   │              │              │              │             │
   │              │              │              │             │
   │              │              │              │             │
   │              │              │              │             │
   └──────────────┴──────────────┴──────────────┴─────────────┘
```

**A regra para a turma:**

> "Enquanto o colega fala, vocês anotam. Toda vez que alguém citar uma
> tecnologia, marquem um risquinho. Se for a primeira vez que aparece, escrevam
> o nome. No final, esse quadro vai mostrar quem nós somos."

**Quem escreve no quadro:** peça dois voluntários que se revezam. Isso libera
você para conduzir as perguntas e observar a turma.

## O fechamento da dinâmica — 3 minutos

Quando o último aluno terminar, pare e leia o quadro em voz alta.

> "Olhem para esse quadro. Isso aqui não é o que vocês vão aprender — é o que
> vocês **já sabem**. Nesta disciplina, quase tudo que está aí vai reaparecer:
> lógica, estrutura de dados, requisição para uma API, versionamento. O que
> muda é o lugar onde o código roda."

Isso emenda direto no slide 05, que mostra a jornada do semestre.
